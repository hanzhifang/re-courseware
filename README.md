# RE-F Interactive Courseware

这是 RE-F 阅读教材课件的独立网页骨架。

## 文件放置

把素材放在同级的 `RE` 文件夹里：

- `RE/REFcover.png`：打开课件后的第一层封面
- `RE/unit1.png` 到 `RE/unit12.png`：目录缩略图和各单元首页

## 打开方式

打开 `RE-courseware/index.html` 即可使用。

如果用本地预览服务，当前可访问：

`http://127.0.0.1:4174/RE-courseware/index.html`

## 当前功能

- 第一层：封面图，点击任意位置进入目录
- 第二层：12 个单元目录，每行 2 个缩略图
- 第三层：单元首页，显示对应单元图
- Unit 12 后面已接入 `12A160.png`、`12A161.png`、`12A162.png`、`12A storymap.png`
- 目录卡片会显示每个单元的 A/B 阅读标题和 video 标题
- Unit 12A 六维词汇作业纸初稿：`worksheets/unit12A-six-dimension-vocab.html`
- 多页单元会显示上一页 / 下一页导航
- 单元页工具：画笔、文字、橡皮、颜色、笔迹粗细、撤销、清空
- 每个单元、每一页的标注会自动保存在当前浏览器里
